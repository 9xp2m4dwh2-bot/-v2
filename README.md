# 아테나 v2 — 모델 구조

> "나는 모델에게 환경을 주고, 모델은 사고를 익힌다."

- 프로젝트: pang-w1
- 버전: v2 (2026-11-16)
- 상태: 설계 단계

---

## 구성 요소

| 구성 | 역할 |
|---|---|
| **학습공간** | 실험대. 장면이 놓이는 곳 (도우미/인간이 간섭할 때만 존재) |
| **우주** | 아테나가 이해한 세계. 물리·사회 모두 "수"로 새김 |
| **아테나** | 보고 → 예측하고 → 우주에 새기는 주체 |
| **도우미** | 초반의 눈 + 학습 도우미 (JEPA 등, 꼭 JEPA가 아니어도 됨) |
| **감시 모델** | 아테나의 우주를 감시하는 별도 월드모델 |
| **최종 심판** | 바깥 (시뮬레이터, 현실 데이터) |

---

## 학습 흐름

```text
① 초반 (도우미 시기)
   학습공간에 장면 제시 (인간/도우미)
     → 아테나가 결과 예측
     → 맞힌 개념을 우주에 "수"로 새김 (연산량 최소)
     → 이해 확인
         ├─ 우주 안에서 계속 사고, 새 예측
         └─ 학습공간에서 다른 상황으로 재시험

② 도우미 퇴장
   아테나가 스스로 가능
   + n번째 새김에 도우미 반대 없음 → 퇴장

③ 중후반 (혼자 하는 시기 ≈ 버전 1)
   ├─ 동영상으로 현실 세계를 계속 학습
   └─ 우주에서 호기심 기반 RL
        (호기심 = 아직 안 풀린 문제 탐구)
```

---

## 확장 순서

```text
과학(물리) → 사회·언어 (동영상 학습 → 우주에 "수"로)
```

- 사회 학습 초반: 도우미가 "되는 것 / 안 되는 것"을 지도 (시끄러운 TV 방지)

---

## 새 법칙 발견 루프

```text
우주에서 미증명 영역 탐색
  → 시험할 장면을 학습공간에 직접 생성
  → 실험 (감시 모델이 감시)
  → 최종 심판 확인
  → 우주에 새김
  → 다시 탐색 ↺
```

---

## 첫 실험

1. 공 낙하 위치 숫자만 주고 → 수식을 스스로 찾기
2. 본 적 없는 높이/속도에서도 맞히기
3. 성공 시 → 영상에서 변수 찾기 (눈 붙이기)
